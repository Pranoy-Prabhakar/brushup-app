Build a simple responsive web application called **Python Brush-Up**.

The purpose is to help developers who already learned Python quickly refresh forgotten Python concepts.

The main goal is:

**"I forgot this Python concept. Help me remember it in 2–3 minutes."**

Do not over-engineer the application.

## Tech

Use:

* React
* TypeScript
* Vite
* Tailwind CSS
* React Router

No backend.

No database.

No login.

Use dark and light mode.

---

## Pages

Create:

* Home
* Topics
* Topic Detail
* Quick Refresher

## Topic Format

Every topic should have:

### What is it?

Short explanation.

### Syntax

Small code example.

### Example

Realistic example.

### When to use

Short explanation.

### When not to use

Only when useful.

### Common mistake

One common mistake.

### Tip

One useful Python tip.

### Remember

One short memory line.

---

## Content Architecture

Keep Python content separate from React components.

For example:

```text
src/
  content/
      basics/
      collections/
      functions/
      oop/
```

Prefer Markdown files.

Example:

```text
src/content/collections/dictionary.md
```

React components should render the content rather than contain individual lessons.

---

## Search

Add a simple client-side search.

Users should be able to search terms such as:

* dictionary
* unique values
* args
* loops
* classes

and open the relevant topic.

## Design

The UI should feel like a combination of:

* developer documentation
* coding cheat sheet
* clean notebook

Keep it simple and compact.

Avoid:

* excessive animations
* large marketing sections
* dashboards
* gamification
* unnecessary dependencies

The site should be easy to keep open beside an IDE while coding.

Build the simplest clean version first.
